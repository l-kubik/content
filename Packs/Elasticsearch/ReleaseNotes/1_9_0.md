#### Integrations

##### Elasticsearch v2

- Added the ***es-update*** command to update a document in Elasticsearch.
- Added the ***es-get-multiple*** command to get multiple documents from Elasticsearch.
- Added the ***es-get*** command to get a document from Elasticsearch.
- Added the ***es-delete*** command to delete a document in Elasticsearch.
- Added the ***es-kibana-case-activity-find*** command to find case activity through Kibana.
- Added the ***es-kibana-case-comment-find*** command to find case comments and alerts through Kibana.
- Added the ***es-kibana-case-comment-get*** command to get a single case comment or alert through Kibana.
- Added the ***es-kibana-case-connectors-find*** command to get the connectors configured for cases through Kibana.
- Added the ***es-kibana-case-creators-get*** command to get the case creators and case counts through Kibana.
- Added the ***es-kibana-case-by-alert-get*** command to get the cases linked to an alert through Kibana.
- Added the ***es-kibana-list-delete*** command to delete a Kibana list through Kibana.
- Added the ***es-kibana-alerts-index-delete*** command to delete a Kibana alerts index through Kibana.
- Added the ***es-kibana-detection-alert-search*** command to find and/or aggregate detection alerts through Kibana.
- Added the ***es-kibana-delete-value-list*** command to delete a value list through Kibana.
- Added the ***es-kibana-case-settings-update*** command to update case settings through Kibana.
- The ***es-kibana-case-comment-delete*** command now supports deleting a single comment or alert by `comment_id` (previously it deleted all comments/alerts).
